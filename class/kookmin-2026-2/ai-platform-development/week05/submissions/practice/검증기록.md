## 원본과 결과 비교

- 확인한 결과 파일: submissions/practice/run01/result.json, report.md / submissions/practice/run02/result.json, report.md
- 직접 대조한 수량과 확인 결과: 창고 A(mug 12, bottle 3, sensor 7) 합계 22, B(mug 5, bottle 9, hub 2) 16, C(sensor 4, hub 11, cable 1) 16, 전체 54로 원본과 일치. 품목별 총수량 mug 17, bottle 12, sensor 11, hub 13, cable 1도 원본 합과 일치.
- result.json과 report.md의 수치 일치 여부: 두 실행 모두 창고별 합계, 품목별 총수량, 저재고 목록이 일치. run02는 practice/tests/check_result.py 검사에서 8개 항목 모두 통과(종료코드 0).

## 1차와 2차 비교

- 1차 저재고 기준과 결과: 창고별 행의 수량 5 미만(warehouse_row) → A bottle 3, B hub 2, C sensor 4, C cable 1 (4건)
- 2차 저재고 기준과 결과: 전체 창고 품목별 총수량 5 미만(item_total) → cable 1 (1건)
- 결과가 달라진 이유: bottle·hub·sensor는 한 창고에서는 5 미만이지만 다른 창고 재고를 합치면 12·13·11로 5 이상이 된다. cable은 C에만 1개 있어 두 기준 모두 저재고다. B의 mug 5는 '5 미만' 조건에 해당하지 않아 1차에서도 제외된다.
