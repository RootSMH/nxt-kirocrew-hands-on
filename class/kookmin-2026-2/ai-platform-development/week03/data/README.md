# 발표 준비 자료

`발표안내.md`에서 준비할 내용을 읽고, `주제조사메모.md`와 `내준비메모.md`를 함께 보면 현재 상태를 파악할 수 있습니다.

| 파일 | 담긴 내용 |
|---|---|
| [발표안내.md](발표안내.md) | 목적, 준비 기준, 날짜, 필요한 파일 |
| [주제조사메모.md](주제조사메모.md) | 공식자료에서 확인한 내용, 내 해석, 출처와 남은 질문 |
| [내준비메모.md](내준비메모.md) | 진행 상태, 개인 일정과 우선순위 |
| [준비작업.csv](준비작업.csv) | 작업별 남은 예상 시간과 상태 |
| [작업가능시간.csv](작업가능시간.csv) | 실제로 작업할 수 있는 시간창 |

작업 상태는 `todo`(시작 전), `in_progress`(진행 중), `done`(완료)입니다. 시간은 분 단위이며 완료한 작업의 남은 시간은 0입니다. 일정의 `+09:00`은 한국시간을 뜻합니다. 예상 시간과 사용 가능한 시간은 자신의 상황에 맞게 조정하고 메모에도 함께 반영합니다.

공식자료에서 확인한 사실과 자신의 해석은 구분해 남깁니다. 출처 링크가 있다는 이유만으로 발표에 쓸 문장의 근거 확인까지 끝난 것은 아닙니다.
