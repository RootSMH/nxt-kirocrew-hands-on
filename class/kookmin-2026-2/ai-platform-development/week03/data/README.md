`교수님에게 전달받은 발표안내 내용.md`와 `주제조사메모.md`를 읽고, 손글씨 준비 메모를 보며 현재 상태를 파악합니다.

| 파일 | 담긴 내용 |
|---|---|
| [교수님에게 전달받은 발표안내 내용.md](<교수님에게 전달받은 발표안내 내용.md>) | 교수님께 전달받은 목적, 준비 기준, 날짜, 필요한 파일 |

| [내준비메모.png](내준비메모.png) | 손으로 적고 고친 준비 상태와 일정 |

손글씨 메모는 직접 본 뒤 Crew 대화에 이미지로 첨부합니다. 읽기 어려운 글자, 수정한 흔적, 아직 정하지 않은 시간은 바로 확정하지 않고 질문으로 남깁니다.

내가 확인한 상태와 일정은 개인 작업 폴더에 정리합니다. 이후에는 판독하고 확인한 메모를 같은 JSON 구조로 저장하는 스킬을 직접 만듭니다.

`다음메모.png`는 시작하기 8단계에서 같은 스킬을 다시 쓸 때 첨부합니다. 첫 업무에서는 `내준비메모.png`만 읽습니다.

공식자료에서 확인한 사실과 자신의 해석은 구분해 남깁니다. 출처 링크가 있다는 이유만으로 발표에 쓸 문장의 근거 확인까지 끝난 것은 아닙니다.
