# Week 03 · 내 일을 맡기고, 규칙과 스킬로 이어가기

[시작하기.html](시작하기.html)에서 자료를 읽고 직접 진행합니다. 첫 업무에서 확인한 기준을 스킬로 만들고, 프로젝트 규칙과 현재 상태를 다음 작업에 이어갑니다.

## 처음 자료 받기

Clone한 수업 저장소의 터미널에서 `git status`와 `git remote -v`를 확인합니다. 수정한 파일은 본인 작업만 먼저 커밋합니다. 다음 명령을 한 줄씩 실행하고 결과를 확인합니다.

```bash
git config --local pull.rebase false
git pull --no-edit upstream main
```

첫 줄은 이 저장소에서 처음 한 번 설정합니다. `--no-edit`는 기본 병합 메시지를 사용해 편집창을 생략합니다. Pull이 완료되면 `git push origin main`으로 자신의 포크에 반영합니다. 충돌이나 오류는 현재 상태를 보존하고 강사와 확인합니다.

## 이번에 하는 일

1. 발표 안내와 조사 메모를 읽고, 손글씨 메모를 이미지로 첨부해 준비 상태를 정리합니다.
2. 내가 확인한 내용과 개인 조건을 반영해 쓸 수 있는 준비 계획을 만듭니다.
3. Kiro Crew의 새 스킬 만들기 화면에서 MD 지침을 만듭니다. 기존 발표 준비 세션에서 스킬 이름을 지정해 실제 `SKILL.md`의 경로와 내용을 먼저 확인합니다.
4. 그 스킬 폴더의 `scripts/`에 Python 프로그램을 추가하고 지침의 실행 절차를 다듬습니다. 첫 사진으로 실행·검토한 뒤 다른 손글씨 메모에 다시 사용합니다.
5. 여러 작업에서 지킬 규칙을 Steering으로 저장하고 실제 적용을 확인합니다.
6. 인계 파일을 작성하고 새 세션에서 명시적으로 읽어 이어갑니다.
7. 내 시나리오에 적용한 결과와 확인한 내용을 자기 포크에 남깁니다.

## 파일 역할

| 위치 | 내용 |
|---|---|
| [data/](data/README.md) | 발표 안내·조사 메모·손글씨 준비 메모 |
| [시작하기.html](시작하기.html) | 스킬 생성·확인·수정과 실행을 진행하는 안내 |
| [나의기준.md](submissions/나의기준.md) | 내 판단·조건·반복할 절차·공통 규칙 |
| [실습기록.md](submissions/실습기록.md) | 실제 실행·검토·개선 기록 |
| [인계.md](submissions/인계.md) | 다음 세션이 읽을 현재 상태와 다음 행동 |

`submissions/skills/`는 최종 사용한 스킬의 지침과 코드를 레포에 남기는 사본 위치입니다. 스킬을 처음 만드는 위치는 아닙니다. 개인 메모와 계획·JSON 결과는 `submissions/`에 두고 데이터 원본은 보존합니다.

AI는 손글씨의 취소선·X·밑줄·화살표·체크 표시를 해석하고 애매한 부분을 질문합니다. 사람은 판독을 확인하고, Python은 확인한 내용을 항상 같은 JSON 구조로 검사해 저장합니다.

채팅의 워크스페이스에는 `class/kookmin-2026-2/ai-platform-development/week03` 폴더를 연결합니다. Steering은 그 프로젝트의 공통 규칙이며, 인계 파일은 현재 상태를 알려주는 문서입니다. 각각 실제로 읽혔는지 확인합니다.

Python 프로그램은 현재 컴퓨터의 명령과 버전을 확인한 뒤 실행합니다. 준비 방법은 [시작하기의 Python 안내](시작하기.html#python-ready)에 있습니다. 자료의 성격과 공개 출처는 시작하기 하단에서 확인할 수 있습니다.
