## 7. 가능한 운영안

- **운영안 A — 현재 확정 140명으로 진행.** 규정상 기본 구매 인원(CLUB-01 제1조), 예정비용 460,000원. 즉시 실행 가능.
- **운영안 B — 대기자 40명 전환해 180명으로 준비.** 변경된 정원 이내이나, 담당자 승인·재원 확인 필요(CLUB-01 제3조). 예정비용 560,000원. 신청자 자동 확정은 안 됨(CHANGE-SPACE-04).
- 어느 안이든 **학교지원금 잔액(250,000원)이 학교지원금 예정비용(140명 256,000 / 180명 312,000)보다 적다.** 지원금 추가 지급 또는 회비 보전 여부를 반드시 확인해야 한다. 변경 승인서는 예산 증액을 승인하지 않았다.

## 8. 추가 확인 사항

- **학교지원금 잔액 부족**: 잔액 250,000원 < 구매 예정비용(학교지원금분). 추가 지급 한도·시점 확인 필요(잔여 승인액 500,000원은 정산 후 지급 예정, 현재 가용 아님).
- **외부인 참가**: 결정된 규정 없음(MEMO-04). 결정·문서화 전까지 허용 근거 없음.
- **인화비 용도 미기재 건**: 영수증·사용 목적 재확인 대상(MEMO-04).
- **대기자 40명 전환**: 정원(180)은 여유가 있으나 재원·물품·담당자 승인 확인 후 순서대로 전환(CLUB-01 제3조).
