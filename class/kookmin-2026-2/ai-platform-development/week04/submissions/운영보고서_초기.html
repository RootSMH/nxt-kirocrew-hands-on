6. 가능한 운영안

  • 운영안 A — 현재 확정 140명 기준으로 진행. 규정상 기본 구매 인원(CLUB-01 제1조)에 부합하고 예정비용 460,000원. 정원(160) 이내라 즉시 실행 가능. 대기자 전환 여부는 승인 후 별도 반영.
  • 운영안 B — 승인 정원 160명까지 대기자 전환. 승인 정원 이내에서 대기자를 신청 순서대로 전환(CLUB-01 제3조). 예정비용 510,000원. 준비 물품·재원을 함께 확인한 뒤 담당자 승인 필요.
  • 운영안 C — 180명(홍보 정원)으로 확대. 유효한 변경 승인서가 발급되어야만 가능. 현재는 근거 없음이므로 승인 전 실행 불가. 예정비용 560,000원은 참고 시나리오.

어느 안이든 학교지원금 잔액(250,000원)만으로는 학교지원금 예정비용(140명 기준 256,000원)을 충당하기 어려우므로, 지원금 추가 지급 또는 회비 보전 여부를 함께 확인해야 한다.

7. 추가 확인 사항

  • 정원 정정: 홍보물 180명 → 승인 정원 160명 정정 검토 필요(APPROVAL-SPACE-04). 180명 변경 승인서 발급 여부 미확인.
  • 외부인 참가: 결정된 규정 없음. 운영회의에서 미결(MEMO-04). 결정·문서화 전까지 허용 근거 없음.
  • 학교지원금 잔액 부족: 잔액 250,000원 대비 구매 예정비용(학교지원금분)이 크다. 추가 지급 한도·시점 확인 필요.
  • 인화비 용도 미기재 건: 영수증·사용 목적 재확인 대상(MEMO-04).
  • 대기자 40명 전환 시나리오: 정원·재원 확인 후 별도 계산 필요(CLUB-01 제3조).
