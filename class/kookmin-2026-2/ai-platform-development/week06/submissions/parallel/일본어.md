# 学科AIハンズオン勉強会のご案内

## 概要

学科の仲間と一緒にAIを実際に使ってみるハンズオン勉強会を開催します。定員は12名で、AIハンズオンが初めての学生も参加できます。この日本語のご案内は勉強会の情報を理解していただくために提供するものであり、当日のご案内とハンズオンはすべて韓国語で進行します。翻訳されたご案内を読んでいただいた場合でも、実際の勉強会は韓国語で行われる点をご確認ください。

## 開催情報

| 項目 | 内容 |
|---|---|
| 日時 | 2026年10月16日 18:30〜20:00（韓国時間、Asia/Seoul） |
| 場所 | 学生会館の集会室 |
| 定員 | 12名 |
| 持ち物 | 個人のノートパソコンと充電器 |
| Wi-Fi | 会場でWi-Fi利用可（パスワードや接続方法のご案内はありません） |
| 参加費 | なし |
| 進行言語 | ご案内・ハンズオンともに韓国語 |
| 参加対象 | AIハンズオンが初めての学生も参加可能 |

## 申し込み方法

参加を希望する学生は、2026年10月14日 18:00（韓国時間）までに学科のグループチャットにお名前を残してください。別途の申し込みリンクはありません。締め切りの日時をご確認のうえ、ご案内された方法でお申し込みください。
